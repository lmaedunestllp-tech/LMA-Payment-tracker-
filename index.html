⚙️ One-Time Setup Required

To connect this app to Google Sheets (so all 3 users share the same data), please enter your Google Apps Script Web App URL below. You only need to do this once.

1

Open Google Sheets

Go to sheets.google.com → Create a new blank spreadsheet → Name it "LMA EduNest Data"

2

Open Apps Script

In the spreadsheet: Extensions → Apps Script → delete any existing code → paste the full Code.gs file contents

3

Run Setup Once

In Apps Script: select setupSheets from the dropdown → click Run → allow permissions when asked

4

Deploy as Web App

Deploy → New Deployment → Web App
Execute as: Me | Access: Anyone
Copy the Web App URL and paste it below
